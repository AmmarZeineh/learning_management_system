# CourseCraft — Learning Management System (Flutter)

A Flutter-based **Learning Management System (LMS)** supporting two roles:
- **Instructor:** create courses, upload content, manage quizzes, chat
- **Student:** browse & enroll in courses, watch videos, take quizzes, chat

---

## ✨ Key Features
### Instructor
- Auth: signup / login / forgot password
- Create & manage courses
- Upload course files & videos (file picker)
- Create quizzes and view quiz details
- Instructor chat with students
- Profile management

### Student
- Auth: signup / login
- Browse all courses + search
- Course info and registration flow
- Watch course videos
- Take quizzes
- Chat with instructors
- Profile + “My Courses”

### Shared
- Comments / ratings (where applicable)
- Bottom sheets for quick actions and quiz flows

---

## 🧱 Architecture & Patterns
- **State management:** BLoC / Cubit (`flutter_bloc`)
- Separation by modules:
  - `views/` (UI screens for instructor/student)
  - `cubits/` & `scubits/` (state management for different domains)
  - `services/` / `sservices/` (API / Firestore helpers)
  - `models/` / `smodels/` (data models)

---

## 🛠️ Tech Stack
- Flutter / Dart
- flutter_bloc (BLoC/Cubit)
- Firebase Core + Cloud Firestore (real-time chat / data)
- HTTP (where needed)
- file_picker
- url_launcher
- svg_flutter
- equatable

## 🔐 Configuration
- Uses `firebase_options.dart` generated by FlutterFire.
